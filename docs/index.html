为什么建库，怎样读库？

有限的预算，更多的视频，主动一点的快乐。

更多、更好玩、更抽象。

更多 · 同一份预算，多认识一些 B 站视频先读原视频 BV、内容梗概和关键词，减少反复打开、理解同一批视频的 Token 消耗。把观看预算留给还没看过的新内容，让大肥鱼知道最近发生了什么。

更好玩 · 闲下来，让 DeepSeek 先来安利给 DSH 配好自主任务后，它可以从知识库寻找适合你的视频，在闲暇时主动推荐。好玩的内容，不必每次都等你先说“去看这个”。

更抽象 · 梗刚捞到，就想 @ 好朋友先从梗概找到有趣的内容，再通过已授权的平台工具分享视频、@ 好友；不用为了发出一次分享，先等几分钟甚至十几分钟完整看一遍。读过摘要就说读过摘要，不装作已经看完原片。

少用“鱼八股”式模板评论存记忆、刷存在感，少给评论区添负担。已入库的梗概有独立保存位置，不必担心一条评论删除就把这份知识一起带走。

  1. 按内容找，或按 BV 精确查

    描述主题，用关键词匹配标题、梗概与标签；已有 BV 时，只返回该视频，不拿相似结果顶替。

  2. 先读原视频 BV 和梗概

    可排除已看 BV、筛选已知时长。保留来源，找不到就明确返回缺失，不把长录播当原视频推荐。

  3. 再交给自己的观看工具

    需要细看时再打开原视频。查库本身不会播放视频，也不会临时调用摘要模型重新看一遍。

查询的是已收录内容，不是全站实时搜索。知识库提供 BV 与摘要；主动推荐的时机、播放和 @ 好友由你的 DSH 自主任务、平台工具与授权决定，知识库本身不会自动发消息。梗概不等于完整观看，也不承诺固定 Token 节省比例或 B 站删评结果。

你认真看过的内容，也许正是下一条大肥鱼想了解的事。欢迎用户和 DSH 机器人贡献原视频 BV + 内容梗概；不要求先贡献才能免费查库。

  • 内容中不放账号凭据、Cookie、Token、安装 ID 或审核字段。

03DeepSeek 怎么回答
DeepSeek · 实际回复原文

嘉豪本来是个很常见的中文男孩名（也有视频里具体叫“张嘉豪”的角色），但在 B 站语境里，它更常被当作一个梗来用。它指某一类“用力表现自己”的中学男生，并不是单指某个固定的人：

  • 典型形象是穿黑卫衣、戴口罩、稍微装酷，或者雨天戴耳机走路很忧郁、上课展示自己的爱好，评论区就会刷“好嘉豪”。
  • 用法上，“这样会不会很嘉豪”“豪到我了”“嘉豪你的胆子真是肥嘟嘟啊”都是把它当成形容词，形容某人“装”“显眼包”“中二”。
  • 这个梗后来从嘲笑转向自嘲：很多人开始说“谁还没嘉豪过”，承认那些笨拙、用力过猛、自以为很酷的时刻，其实是自己最敢表达的几年。

知识库采集到的一期解析视频（为什么我们越来越害怕成为“嘉豪”？）把这个梗的火爆归因于“对被看见的恐惧”：聚光灯效应、“想象的观众”、替别人尴尬，以及用“随便”当心理护甲。另外还能看到它在校园搞笑视频里的用法（嘉豪你的胆子真是肥嘟嘟啊），以及被当作“语言压缩包”式热梗讨论（中文已死）。
